AI Security Institutes tracker

API v1

Static JSON files, version 1.1.2-dev, data as of 2026-11-20. Each record file holds the record as in the full dataset with the sources it cites.

  • index.json: The same overview as JSON: files, URL patterns and how to read the records.
  • jurisdictions.json: Every jurisdiction in one compact list: id, name, status, status_since and AISI id (institute).
  • jurisdictions/{id}.json, for example jurisdictions/GB.json: Everything on one jurisdiction (ISO 3166-1 alpha-2 code, EU for the European Union): its record as published in the full dataset, its AISI's record under institute (null when there is no AISI), and the sources both cite with their supporting excerpts.
  • institutes/{id}.json, for example institutes/gb-aisi.json: One AISI as published in the full dataset, with the sources it cites and their supporting excerpts.

The full dataset is data/aisi.json. For how to read the records, see llms.txt.
